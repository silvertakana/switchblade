Models

A logical model id bound to one or more providers (backend + upstream). Declared order is the failover order.

Presets

Routing policies exposed to clients as model ids. A preset may list other presets (tier nesting); the top-level strategy governs.

Settings

Server-level blocks. port and host are bound at startup and are not editable here.

Environment

Where each name comes from, and whether the running process has it yet. managed values live in the secrets store and are editable here; a shell value is owned by the platform and is read-only; saving a new value for a .env name takes it over by moving it into the managed store, which outranks the file.
